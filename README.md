# Pack 7083 Wolf Den Site

This repository hosts the GitHub Pages site for the Pack 7083 Wolf den reference page.

## Edit the site from GitHub

You can update the site directly in your web browser without installing Git, using a local editor, or working from the command line.

### Quick edit link

- Edit the page content here: [index.md](https://github.com/jonathanhood/den-infosite/edit/main/index.md)

### What to edit

- The main page content lives in [`index.md`](https://github.com/jonathanhood/den-infosite/blob/main/index.md)
- Most text changes can be made there directly
- The calendar embed is also in that file

### How to make a change in GitHub

1. Open the edit link above.
2. Sign in to GitHub if prompted.
3. Make your text changes in the browser.
4. Use the **Preview** tab if you want to check the formatting.
5. Scroll down to **Commit changes**.
6. Enter a short description of what you changed.
7. Choose **Commit changes**.

GitHub Pages should publish the updated site automatically after the change is committed.
